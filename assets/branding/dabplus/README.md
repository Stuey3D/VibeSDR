# DAB+ logo — WorldDAB brand toolkit

`DABplus_Logo_Colour_sRGB.svg` is the official DAB+ logo from the WorldDAB "DAB+ branding and
toolkit" (https://www.worlddab.org/resources/marketing-dab-plus/dab-plus-logo), unmodified.

What the toolkit's own README and the International English Style Guide (2018-06) say, and what we
follow:
- Available **free of charge for promotional purposes to all market partners**; presentations other
  than those in the guide are prohibited — so it is the official artwork, unaltered, never redrawn.
- Colour version: DAB+ green PANTONE 376 C / sRGB 134,221,37 and DAB+ cyan sRGB 0,189,210.
- **Minimum 32 px wide on screen** (8 mm in print). The badge is drawn at 36 px.
- The secondary black/white version exists for co-branding and monochrome media; we use the
  colour version on our dark surfaces, which the guide permits ("on white, black or other
  coloured background").

Where it appears: beside a receiver that can decode DAB — the receiver chooser (app and web), and the
public directory. It is a statement that the receiver is set up for DAB+, drawn only when the server
reports `dab: true` for that radio; never as decoration.
