NAVTEX fixtures — a small curated set of REAL NAVTEX messages (public maritime safety broadcasts) received by Stuart's
Lenovo VibeServer (RSP1A, IO92nh) in October–November 2026: one message per station and band seen (three of the
undecided "Station F" on 518 kHz, which are Tallinn), as that server's gallery saved them — `index.jsonl` (its index
lines, newest first) and `files/`. Used by scripts/test-web-navtex-map.mjs and vibeserver/test-navtex-map.cpp.
The full sets (~4 500 Lenovo, ~15 000 UberSDR messages) stay outside git (~/VibeSDR-test-audio/navtex-*).
