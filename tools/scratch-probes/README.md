# Scratch probes

One-off measurement scripts from debugging sessions (mostly the DAB receiver, summer–autumn 2026), moved here from
the top of the repository on 2026-10-14 to tidy it. They are kept, not deleted, because the project commits its dead
ends as well as its fixes: each one is the evidence behind a commit message.

They are not maintained and are not part of any build or test. Most were written to run from the repository root
(`node <name>-tmp.mjs`) against a live VibeServer, so any relative paths in them assume that location.
