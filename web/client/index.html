WHAT THIS RECEIVER HAS LEARNED

    

      
      
      
    

    
Stations are learned from RDS as people listen, and artwork is looked up once
       and remembered — a day for a hit, an hour for a miss. Clearing the logos makes the next
       listener's lookup fresh, which is the cure for a station showing somebody else's badge.
       Manual bookmarks are the ones you typed or imported; they never expire, and they are kept
       separate here because they are usually the part that is right.

    


    

    
MAINTENANCE

    

      
      
      
      
      
      
    

    
    

      
      
      
    

    

      
      
      
      
    

    

      A receiver in a loft gets logged into roughly never, which makes it the machine most worth
      updating automatically. Update VibeServer upgrades this one package and is safe to run
      daily. Update all packages upgrades the whole system unattended — that keeps security
      fixes current, but an OS upgrade can occasionally need attention and nobody will be watching,
      so weekly is the sensible choice. Both run at the hour you pick, local time.
    

    

    
    

    
    

      There is deliberately no web terminal here. The admin password's other job is guarding the
      gain sliders, and a shell behind it would be full control of this machine and the network
      around it — on a receiver that is publicly listed and served over plain HTTP. The buttons
      above cover what a terminal was wanted for. For a real shell from your phone, put this
      machine on Tailscale or WireGuard: proper key authentication, nothing exposed.

Off — audio always passes.

  

  
  


  
  




  
  
  




    
    

  

  

    Off, audio is compressed to around 10 KB/s. On, you get the raw stream — about 187 KB/s,
    roughly twenty times more, out of the operator's connection. Worth it on a fast link if
    you can hear the difference; a courtesy to leave off if you can't.
